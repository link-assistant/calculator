### Added
- Parity goldens for the native JavaScript port (#254): `parity/corpus.json` lists 2279 inputs (every one-line literal of the Rust tests and every `data/examples.lino` expression, collected by `scripts/extract-parity-corpus.mjs`), and `tests/parity_goldens.rs` records the Rust results in `parity/goldens/` for three scenarios (default, a local timezone, loaded live rates) at a fixed clock and a frozen rate snapshot. `UPDATE_PARITY_GOLDENS=1` rewrites them; `PARITY_VERBOSE=1` prints each case.

### Changed
- Every "now" read goes through `calculator::clock::now()`, which tests can freeze with `clock::set_fixed_now`; `CurrencyDatabase::with_bundled_rates` builds a database from a given rate table.
